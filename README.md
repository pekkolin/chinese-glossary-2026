# 《Chinese Glossary 2026》中文生词教学与学习网页工具

> **专为中文作为第二语言（CSL/CFL）教学设计的现代化全功能 Web 教学工具**  
> 基于 `Chinese Glossary 2026.xlsx` 构建，深度融合多模态第二语言习得（SLA）教学法。

---

## 🌟 核心特色与教学价值

### 1. 完整继承并升华原表格逻辑（Smart Auto-Completion）
* 原 Excel 表格中设计了在 Google Sheets 下“输入英文自动完成中文、发音与释义”的自动化公式，但在脱机或常规 Excel 中经常报错失效。
* 本网页工具内置**智能生词补全引擎**：在输入英文单词（如 `telescope`、`library`、`school` 等）时，系统自动匹配带调拼音、简体中文、繁體中文与双语释义，实现真正的**一键智能建词**。

### 2. 双重编码与多模态发音（Dual Coding & Audio）
* **普通话高保真发音**：集成 Web Speech API 原生语音合成，支持点击即读；
* **慢速跟读模式**：提供 `0.75x 慢速跟读`、`1.0x 标准原速` 与 `1.25x 快速辨音` 调节；
* **真人发音与字源直达**：保留维基词典（Wiktionary）链接，方便学生探究部首与笔顺演化；
* **图像辅助联想**：一键直达 Google 图像库，契合双重编码理论，强化视觉记忆。

### 3. 循序渐进的识字脚手架（Scaffolded Literacy）
* **拼音显隐开关**：学生可在初学期开启拼音，在中高级复习期一键隐藏拼音，检验独立识字能力；
* **简繁双轨切换**：支持简体中文与繁体中文一键全局切换，适配不同地区教学大纲与教材。

### 4. 三大核心交互学习模块
* 📖 **词库全览 (Glossary View)**：实时按字、拼音、英文或释义模糊检索，快速标星掌握状态，自由增删词汇。
* 📇 **3D 双语智能闪卡 (Flashcards)**：
  - 支持 `英译汉`、`汉译英`、`听音辨字` 三种测试方向；
  - 3D 卡片平滑翻转，键盘快捷键操作（`Space` 翻转，`←` / `→` 切换，`P` 朗读）；
  - 掌握程度打标（Mastered vs Need Review），自适应筛选重点攻坚。
* 🎯 **随堂自测与趣味游戏 (Quiz & Games)**：
  - **4选1智能单选测验**：题目自动生成，即时评分与错题深度解析；
  - **记忆连连看 (Match Game)**：汉字与英文卡片配对翻牌消除，寓教于乐。

### 5. 教师专属：一键生成并打印教学材料 (Printable Worksheets)
点击「打印单生成器」即可即时预览并使用浏览器原生 `Ctrl + P` 打印输出：
* **汉字田字格规范描红练习单**：包含范字、浅灰描红格及独立书写格，专为汉字书写作业设计；
* **随堂评估测试卷**：A4 纸面标准排版的中英配对题与拼音汉字填空题；
* **便携裁切生词卡**：双面剪裁线卡片排版，方便打印后作为学生口袋单词卡。

### 6. 数据安全与零依赖
* **纯静态网页**：无需配置 Python、Node.js 或数据库，**直接双击 `index.html` 即可在任意电脑或平板浏览器中流畅使用**；
* **本地数据持久化**：自定义添加的生词保存在浏览器 LocalStorage 中，刷新不丢失；
* **多样化导出**：支持一键导出为 Excel 兼容的 `.csv` 表格、`.json` 完整备份，以及直接导入 Anki 的 `.txt` 记忆库卡片。
